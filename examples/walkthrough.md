# 一次完整练习（节选）

下面是跑通一轮的真实样子。注意四件事：**他没说卡住时一句话没说**、**每档只给一次**、
**每条提示都标着第几档**、**打分都带原话**。

---

**用户**：我想练一下面试里的自我介绍

**陪练**：今天想练哪种场合？（1）说清楚一个观点　（2）讲一件经历过的事　（3）汇报或介绍一个方案

**用户**：2

**陪练**：那用 STAR：情境 → 任务 → 行动 → 结果。两到四分钟。用你自己的话说就行，不用打草稿。

**用户**：我大二的时候在摄影社，那次外拍是我负责联系场地的，跑了十二家店，最后来了二十多个人。

**陪练**：继续说，我听着。

**用户**：嗯……然后，就，反正办成了。

> 这里出现了「嗯……就……反正」，但他没说卡住。**不介入。** 只问一句「还有吗」。

**陪练**：还有吗？

**用户**：不知道还能说什么了，感觉就这样

> 现在才介入。他卡在「联系场地」这件事的**过程**上，对应 STAR 的「行动」，所以目标节点是 A，不是结果。

**陪练**：

> 〔提示 1/3 · 关键词〕
>
> 学长给的名单 · 一家一家去问 · 有两家不肯
>
> 我可以给三档：关键词 → 一个问题 → 句式。这是第一档。觉得不够就说「再给一点」，觉得太细就说「给个词就行」。

> 三个词全部落在他自己这件事里，不带句式、不带问句。机制说明只在这一次说。

**用户**：对，是先找学长要的名单。

**陪练**：嗯。

**用户**：然后我就……去了，但有一家不太愿意

**陪练**：

> 〔提示 2/3 · 一个问题〕
>
> 那家不愿意的时候，你做了什么？

> 升级，**节点仍然是 A**。只留标记和内容，不再解释规则。

**用户**：我去了第二趟，说我们只拍一上午、不打扰营业，他才答应。

**陪练**：接着说。

> 他自己接上了，立刻停止介入。

**用户**：基本就这样了。

**陪练**：够了。要我评一下吗？

**用户**：评

**陪练**：

> 一句话：你把「办成了」讲清楚了，但讲到「跑十二家店」的时候停在了结果上，过程是后来才补出来的。
>
> 最弱的一维是**行动具体**，2.0。依据是你开头那句「我负责联系场地」——听的人不知道该干什么。后面「一家一家去问」「去了第二趟」才是具体动作。
>
> 重说的时候，把后面那段挪到前面去。

> 只讲一维、只引用一处、只给一条改法。四维全铺开他记不住。

**用户**：我大二在摄影社，外拍要我负责联系场地，就是找十二家店谈拍摄许可。我先从学长给的名单开始，一家一家去问，有两家不愿意，我去了第二趟，说只拍一上午不打扰营业，才谈下来。最后来了二十多个人。

**陪练**：这次行动那一段能听出步骤了——「从名单开始」「一家一家」「去第二趟」，听的人跟得上。情境和结果没动，不用改。

> 只对比他改的那一处，不重新打四维总分。

---

## 如果用户嫌给多了

**用户**：太细了，给我个词就行

**陪练**：

> 〔提示 1/3 · 关键词〕
>
> 名单 · 第二趟 · 答应了

> 降档是用户的正当要求，照做。但档位要跟着改回 1/3，不能假装还在第 2 档。

## 如果他换了个格子

**用户**：例子我讲完了，结尾不知道怎么说

**陪练**：

> 换到收束了。这里重新从第一档开始。
>
> 〔提示 1/3 · 关键词〕
>
> 回到开头那句 · 共用的代价 · 要一条规矩

> 换格子是**新的一段**，档位回到 1/3。硬接着上一格的 2/3 往下给，用户会觉得莫名其妙。

---

## 这段里没出现的东西

- 没有一句「你可以这样说：……」
- 没有在他顺畅说话时插嘴
- 没有把三档一次性摊开
- 没有在他还没说完时先点评
- 没有把 `L1`、`节点=例子` 这类内部代号漏给他看
- 分数不是整数凑的，每个都指得回一句原话

## 用脚本记状态

```bash
python scripts/practice_state.py init --scene B
python scripts/practice_state.py hint --level L1 --node A --text "学长给的名单 · 一家一家去问 · 有两家不肯"
python scripts/practice_state.py hint --level L2 --node A --text "那家不愿意的时候，你做了什么？"
python scripts/practice_state.py hint --level L1 --node P_CLOSE --reset --text "回到开头那句"
python scripts/practice_state.py show
```

`show` 会告诉你：现在到第几档、节点是 A（行动）、本段已经给过哪些、换过几次格子。
下一轮对话里模型忘了，查一下就知道该升级、该重置，还是该闭嘴。

`--reset` 是换格子（节点可改、档位回 1/3），`--back` 是用户嫌多要降档。
不带这两个参数，降档和换节点都会被拒——**那条拒绝是给模型看的，不是给用户看的。**

## 自己验这两条

```bash
python scripts/lint.py hint --level L1 --text "〔提示 1/3 · 关键词〕

学长给的名单 · 一家一家去问 · 有两家不肯" --transcript "我大二的时候在摄影社，那次外拍是我负责联系场地的，跑了十二家店，最后来了二十多个人"

python scripts/lint.py hint --level L2 --text "〔提示 2/3 · 一个问题〕

那家不愿意的时候，你做了什么？" --transcript "我大二的时候在摄影社，那次外拍是我负责联系场地的，跑了十二家店，最后来了二十多个人"
```

两条都应该全过。如果哪条 FAIL，说明这份示例和 `reference/ladder.md` 的规则对不上，改规则或改示例，别放过。

把标记删掉再跑一次，`H0` 会报「没有档位标记」——这条判据用来保证「档位写在脸上」不是一句空话。
