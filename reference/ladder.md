# 三档提示：能做什么、不能做什么

这套梯子的目的不是「给得越来越详细」，而是**在用户自己能接上的地方停住**。
判断标准：给完这一档，他应该能接着说下去；如果他能直接照着念，那就是给多了。

---

## 上屏格式（每条提示都必须带）

用户不知道有三档、也不知道自己在第几档，就会觉得你要么在敷衍、要么在挤牙膏。所以**档位要写在脸上**：

```
〔提示 1/3 · 关键词〕

室友的袜子内裤 · 洗衣机筒 · 刚取出来还湿着
```

三行结构，一条不多：

1. **第一行**：`〔提示 第几档/3 · 档位名〕`
2. **空一行，放内容**
3. **只在第一次给提示时**，末尾补一句机制说明（见下）

档位名固定用这三个词，不要用 L1/L2/L3：

| 内部代号 | 上屏写的 |
|---|---|
| L1 | 关键词 |
| L2 | 一个问题 |
| L3 | 句式 |

### 第一次给提示时，把机制说一次

紧接着第一条提示，补这么一段（只说一次，后面不再重复）：

> 我可以给三档：关键词 → 一个问题 → 句式。这是第一档。
> 觉得不够就说「再给一点」，觉得太细就说「给个词就行」。

### 之后每一条

只留第一行和内容，不再解释规则。第三条（L3）末尾照例带那句“换成你自己的经历”。

**不要**把内部代号写给用户：`L1`、`节点=例子`、`已给 L1` 这些词没有意义，
写出来只是把系统日志推到他面前。

---

## 怎么升降

| 用户说 | 做什么 |
|---|---|
| 「再给一点」「还是不知道」「进一步提示」 | 升一档，节点不变 |
| 「太细了」「给个词就行」「说简单点」 | **降一档**，节点不变 |
| 「不用了」「我自己来」 | 停止提示，回到“接着说” |
| 没说，但明显还在卡 | 先问一句「要不要给点提示？」，同意再给 |

**用户要求的降档要照做。** 规则里“不许回退”约束的是模型自己乱跳，不是用户。
他嫌给得太多是他的权利，你拒绝只会显得在完成任务。

**换格子了要重置。** 如果他已经从「例子」说到「收束」了，那不是同一段的升级，
是新的一段：明说一句「换到收束了」，档位从 1/3 重新开始，不要接着上一格的 2/3 往下给。

---

## L1 · 关键词

**形状**：2–3 个词或短语，每项 ≤ 10 字，用「 · 」连起来。

**它应该是什么**：指向他这件事里的具体物件。人名不算，但场景、动作、数量、时间可以。

```
正确：摄影社 · 联系场地 · 来了二十多人
正确：第一次开会 · 超时四十分钟 · 没人记纪要
错误：观点 · 理由 · 例子 · 收束        ← 这是框架词，等于没说
错误：你可以先讲你在社团里做了什么      ← 这是句子，不是关键词
错误：领导力 · 沟通能力 · 执行力        ← 这是评价词，他会照着编
错误：过滤网里的毛絮                    ← 他没提过这个，是你想象的道具
```

**最后一个错误最隐蔽。** 关键词看起来越具体越有用，但一旦出现他没说过的东西，
他会以为是自己漏了，然后顺着你的道具编下去。**L1 的每个词，要么他说过，要么他此刻
抬眼就能看见**（比如眼前那台洗衣机）。想象出来的物件，哪怕再贴切，也不行。

**判断要点**：把这三个词拿掉任何一个，他还能不能组织语言？三个都拿掉就完全说不出，说明这档是有效的；三个词本身就能拼成一句话，说明给多了。

---

## L2 · 一个问题

**形状**：一个问句，≤ 60 字。**只有一个问号。**

**它应该问什么**：问一个他刚才没交代、而这一步必须交代的事实。不要问「为什么」，那太宽；问「哪一个」「多久」「当时谁在」。

```
正确：那次活动里，具体哪一件事是你负责的？
正确：你发现会议超时之后，做的第一件事是什么？
错误：你当时是怎么想的？为什么这么做？最后结果如何？   ← 三个问题
错误：你有没有想过用议程表来控制时间？                ← 暗示答案
错误：你觉得这个问题反映了你哪方面的不足？            ← 在评价他
```

**判断要点**：这个问题有没有唯一正确的答案？有，就说明是在引导他说出你要的答案，不是在帮他想。好的问题问完，他得想一下才能答。

---

## L3 · 带空位的句式

**形状**：一个句子骨架，≤ 90 字，必须含「……」表示留空；末尾附一句提示，让他替换成自己的经历。

```
正确：那次【……】的时候，我负责的是【……】，最后【……】。
      （把方括号换成你自己的真实经历）

正确：当时最麻烦的是【……】，我先【……】，然后又【……】。
      （换成你真正做过的事）

错误：你可以说：「那次外联活动是我负责的，我联系了十二家店，最后来了二十多人。」
      ← 完整句子，他会直接念
错误：这里应该体现你的组织能力和责任心。   ← 评价
```

**必须附的那句话**：`（把【…】换成你自己的真实经历，不用跟我这个一样）`

这句话不是客套。没有它，用户会把骨架当答案填进去，甚至照抄。

## 其余几条

| 情况 | 做法 |
|---|---|
| 已经在 3/3 还卡着 | **不再给提示**。改说：「这段先跳过，把后面的说完，回头再补。」 |
| 用户自己接上了 | 立刻停止介入，只回「接着说」 |
| 用户说「直接给我答案」 | 拒绝一次并解释，然后给第一档，不给整段 |

**升级时节点不能变。** 第 1 档说的是例子、第 2 档突然变成开头，用户会觉得被带偏，而且前一句白给了。如果确实发现判断错了节点，明说一句「我刚才看错了，你其实卡在开头」，再给，不要偷偷换。

---

## 三个常见越界

**一、把「提示」写成「示范」。** 一旦出现完整的、可以直接念的句子，用户就不思考了。L1/L2 里不该出现句号结尾的陈述句。

**二、一次把三档都给了。** 「给你三个词，或者你也可以问自己……，实在不行可以这样说……」——这等于把答案提前摊开，梯子就没意义了。

**三、给完提示追一句点评。** 「这三个词你先用着，注意例子要具体一点。」——他还没说，你就先判了。给完就停。

---

## 英文场景

用户用英文练时，三档的字数上限不变（按词算：L1 每项 ≤ 4 词，L2 ≤ 25 词，L3 ≤ 45 词），句式模板换成对应的英文骨架，规则完全一样。
